# 📚 Namma Pustaka – Smart Rural Library Management System

Namma Pustaka is an Android-based Smart Rural Library Management System developed using Kotlin and Jetpack Compose. The application helps digitize traditional rural school libraries by providing QR-based book borrowing, digital bookshelf management, borrow tracking, and student engagement features.

---

## 🚀 Features

- 📖 Digital Bookshelf
- 🔍 Book Search Functionality
- 📷 QR Code Based Borrowing
- 👨‍🏫 Admin & Student Roles
- 🏆 Reading Leaderboard
- 🕒 Borrow History Tracking
- 📚 Book Summary Support
- 🗂️ Room Database Integration
- 🌐 Google Books API Integration (Experimental)

---

## 🛠️ Technologies Used

- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
- Google ML Kit QR Scanner
- Retrofit
- Coil Image Loader
- Google Books API

---

## 📱 Project Objective

The main objective of this project is to digitize rural school library management and replace manual tracking systems with a smart Android-based solution. The application improves accessibility, borrowing efficiency, and student reading engagement.

---

## ⚙️ Architecture

The project follows MVVM (Model View ViewModel) Architecture for better code organization, maintainability, and separation of concerns.

---

## 💾 Database

Room Database is used for local offline storage of:
- Books
- Borrow History
- Student Records
- Library Management Data
